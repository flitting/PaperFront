### 本稿的使用说明

本稿依据当前讨论中的最新选择重新整合，不是早期设定的逐字副本。采用“架空近现代工业战争＋儿童造物神话＋严肃的工业宗教”路线，不再沿用森林聚落、自然部落等旧方向。

正典军团、重锤军团沿用既定设计图中的名称，铁钉同盟与天翼教团使用当前统一名称。后两方以本轮“认真可靠的工业工艺”与“简陋纸模外壳、真正先进功能”的说明为准。

文中的背景、人物与战役桥段属于策划设定，并不表示所有内容已经在游戏中实现。阵营战略定位是设计方向，不是经过实战验证的平衡结论。后两阵营的当前单位、支援参数与实现边界见[单位与支援体系修订](../expansion_factions.md)，游戏规则与该补丁说明优先于本文中的长期战役构想。

# 1. 核心定位

《纸境战线》是一款发生在手工微缩世界中的架空工业战争 RTS。

几位孩子在同一张长桌上，分别用纸板、纸浆、木条、颜料和连接件制造了自己的军团。孩子们彼此比较模型、修改设计，并各自认定自己的军团应该获胜。

当他们离开房间，模型世界仍在运转。矿车驶向矿区，工厂复制原型，飞机从纸板跑道升空，军官依据神授图纸签署进攻命令。

军队不知道“小孩子”是什么。他们把那些能从天际伸下巨手、裁开地貌、放置建筑并赋予生命的创造者，称作 **造形诸神**。

每个阵营都认真相信：自己的创造者留下了正确的世界设计，其他军团则遵循错误、过时或未经认可的图纸。争夺矿区和工业走廊的战争，因此也被解释为消灭异端、确立正统的使命。

**对玩家而言，这是几个孩子拼出的势力之间的角逐；对角色而言，这是决定家园、信仰与生存的真实战争。**

## 1.1 三条核心原则

1. **材料具有玩具感，人物不能把战争当作玩笑。** 模型可以短粗夸张，军队仍有纪律、感情、损失和责任。
2. **宗教解释工业，不能替代工业。** 神明赋予设计，军团依然需要资源、电力、制造、运输和维修。
3. **笑点来自庄严解释与微小起源之间的反差。** 不是士兵主动讲段子，而是他们严肃执行的神谕，可能只是孩子随口说的一句话。

## 1.2 游戏的基本目标

采集资源，建立基地，扩充工业与军队，取得地面和空中优势，摧毁敌方基地体系，赢得正统之争。

“消灭异端”是军团对战争的宗教表述；实际胜利由明确的 RTS 规则判定，例如摧毁所有可计入基地存续的总部与分基地。不要让剧情中的宏大措辞取代清楚的游戏目标。

# 2. 创世与世界运行规则

## 2.1 四种制作习惯，成为四套正统

最初的孩子有不同的制作习惯。

- 一位喜欢用尺子裁齐边缘，给零件编号，要求照着图纸组装。
- 一位喜欢厚装甲、大炮和更重的模型，总说自己的装备更厉害。
- 一位总要检查连接牢不牢，用厚纸板补强承重部位，并承诺把交出去的装备认真维护好。
- 一位想法很多、拼得很快，把纸筒粘在盒子上就宣布是先进武器，并坚信简陋外壳不会限制真正的高科技。

这些习惯成为阵营最初的形态来源。后来，造物们建立自己的制度、历史和解释体系，才形成今天的四方。

**孩子的偏好不直接决定阵营善恶。征用、保护、侵略或救助，是军团自身制度与选择的结果。**

## 2.2 神创造第一份设计，工业负责复制

造形诸神能够制造第一件真正具有功能的原型：一辆会行驶的坦克、一架能够飞行的飞机、一名拥有意识的士兵。

神授功能通过原型与图纸传承。军团掌握设计后，可以在工厂和训练设施中复制、装配和培养后续单位，但每一次生产都必须付出资源与时间。

神说“这个能飞”，并不意味着所有地面车辆也能飞；神说“这门炮特别厉害”，也不代表它不需要能源、装填和散热。

> **神可以赋予一种可能，不能替军团无成本地完成所有生产。**

## 2.3 神谕不是战斗中的任意改规则

诸神的介入稀少、不可预测，军团不能可靠召唤。

新草图可以成为某次重大科技进展的起源，但不能反复作为“即将战败，所以神突然加入无敌兵器”的解决办法。

不同阵营共享基本规则。被宣称“绝对无敌”的坦克仍可能被击毁。军团会争论制造是否合格、指挥是否正确、神谕是否被误读，但战斗结果不会被任意推翻。

## 2.4 世界里的物体不是普通文具的物理复刻

它们确实具有纸板切边、纤维、涂层和接缝，但神授功能与工业处理使其构成一个稳定世界。

水体、燃烧、装甲、动力与飞行遵循游戏自己的统一规则。普通河水不会让整个文明瞬间泡散，任何阵营也不能靠点燃一角地图自动毁灭世界。

材料身份用来解释美术和制造文化，不应制造无法维持玩法的漏洞。

## 2.5 生命与损失

角色知道自己的躯体与装备由纤维、构件和连接件组成，却不会因此认为自己是没有意义的玩具。

他们会害怕、忠诚、犹豫、争取晋升，也会记住共同服役的人。

损坏表现为裂口、断件、倒塌、烟团与残骸，不需要血腥。维修可以修复尚可工作的装备，但按照相同型号重新制造出来的单位，不自动等于原个体复活。

**战争必须有代价，不能设定成所有损失在第二天自动重置。**

# 3. 资源、科技与工业生活

## 3.1 统一资源：辉晶

辉晶是这个世界的重要工业矿物。矿车采集后，由精炼设施处理，转化为可用于生产与建设的军需额度。

四个阵营使用同一种核心采集资源，电力作为独立的基地运行约束。宗教设定不额外强制增加信仰值、灵魂或法力等资源。

辉晶可以出现不同视觉颜色，但矿物颜色不代表玩家所有权，也不意味着不同阵营必须分别采集蓝矿、红矿或其他专属矿物。

矿车属于谁，应通过其玩家识别区判断，而不是通过货物颜色判断。

## 3.2 科技水平

时代基底为架空近现代工业战争，允许不同技术世代经过风格化整合，但仍保持共同的机械语言。

| 技术层级 | 装备内容 | 造型要求 |
|---|---|---|
| 基础机械化 | 步枪、机枪、卡车、装甲车、履带坦克、常规火炮 | 功能轮廓清楚，体块短粗，不追求精密复刻 |
| 成熟工业战争 | 自行炮、防空系统、雷达、运输机、战斗机、攻击机与轰炸机 | 用专业设备区分用途，避免所有载具只换炮管 |
| 高级试验技术 | 电磁炮、脉冲装置、定向能武器、先进能源设备 | 通过线圈、导轨、电容箱、散热片等实体结构表现 |

科幻装备仍应像被认真拼出来的纸模机械。不能突然出现与全局材质完全不同的光滑金属飞船、满屏悬浮界面或纯魔法能量体。

## 3.3 工业即宗教生活的一部分

原图档案馆保存圣典，检验台确认造物是否符合教义，授名仪式决定单位型号，工厂则把神授设计转化为可投入战争的力量。

最庄严的圣堂，可能就是一条昼夜运转的坦克装配线。

所有阵营都有矿业、工业城市、交通、维修和行政组织。“军团”“同盟”“教团”是对整个势力的简称，不意味着其社会只剩战斗人员。

## 3.4 世界的主要环境

环境围绕工业战争组织：河谷矿区、铁路节点、机修城市、军港、航空基地、层叠高地与旧城废墟。

森林是地貌与战场环境，不是独立的自然部落文明。石墙和半毁石质建筑可以来自早期城镇或历次战争遗迹，不必因此添加古代精灵或魔法王国。

# 4. 战争目的与历史时间线

## 4.1 战争为何持续

信仰决定每方认为谁有统治资格，资源和战略位置则决定战争如何进行。

同一座桥，可能连接矿区、工厂与前线基地。正典军团依据维护标准主张管理权；重锤军团依据接收命令要求控制；铁钉同盟依据载荷保证和工程维护责任要求保留检修通道；天翼教团则以新观测设备和航空运输方案主张重新安排通行。

四方都能出示严肃的文件，也都认为其他文件无效。

随后，炮兵开始处理争议。

## 4.2 初裁历

“初裁历”是模型世界内部的纪年，与外部孩子经历的日历没有固定对应关系。

| 时间 | 事件 | 历史结果 |
|---|---|---|
| 初裁元年 | 第一次裁形 | 最早的基地、军队与原型获得生命，原始设计成为圣物。 |
| 初裁三年 | 四角立旗 | 四个工场发展出不同的军队、制度与创世解释。 |
| 初裁六年 | 辉晶矿脉开发 | 工业生产扩大，原型开始被大规模复制。 |
| 初裁九年 | 四角协约 | 各方暂时划分矿运路线和势力范围，但没有承认彼此信仰同等正确。 |
| 初裁十四年 | 修订争议 | 新图纸能否高于旧图纸引发冲突，正典与天翼关系恶化。 |
| 初裁十七年 | 大压印令 | 重锤以统一裁决为由接收跨界矿区，公开破坏原有秩序。 |
| 初裁十八年 | 第一次保障冲突 | 重锤接管机修走廊并要求保障线服从进攻，铁钉认为这破坏人员撤离与工程质量承诺，冲突扩大。 |
| 初裁十九年 | 无字桥事件 | 多方运输与驻防部队出示互相矛盾的通行授权，交火扩大。 |
| 初裁二十年 | 最终定稿战争 | 争端扩展为全面工业战争，各方争夺生产能力、交通与制空权。 |

“最终定稿”不是世界真的将要完成，而是每个阵营都宣称：自己获胜之后，其他版本就不再有存在的必要。

## 5.3 四种形态，而非四种颜色

- **正典：**规整拱架、梯形支撑、清楚的装配秩序。
- **重锤：**低伏楔形、厚压梁、层叠装甲和巨大夹臂。
- **铁钉：**厚实纸板、宽连接片、牢固支撑、标准护板与整齐工具区。
- **天翼：**少量大纸盒、粗纸筒、大折板、手画设备线与可读的胶接。

全部阵营共享纸板与手绘微缩模型风格。身份依靠形体、构造、徽记和材料处理共同建立，不能只依靠蓝、红、灰、白等颜色。

# 6. 正典军团

## 6.1 身份与口号

> **“按图建造，按令前进。”**

正典军团相信，世界存在可以被理解、检验和维护的正确结构。战争的使命，是保护这些结构并修正危险偏差。

它适合作为首发战役的入门视角：军队有纪律，重承诺，重视道路、工厂和人员损失。但它并非绝对包容，常常把“我们能修好这里”理解成“我们应当管理这里”。

它的善意与傲慢来自同一个根源：相信自己掌握正确答案。

## 6.2 信仰与制度

执尺者留下的原图保存在总部，合法的科技进步必须通过检验与审定。

正典并不拒绝新技术。它拒绝未经认证的修改，并认为任何自称神启的人都需要证明自己的设计。

社会由工程部门、审图机构、军工人员与军队共同维持。“合格”是一项被认真对待的荣誉，而不是平庸的评价。

服役记录、检修编号与授名文件具有身份意义。装备可以有修补，但每一次修补都应说明它被持续维护，而不是随意拼凑。

## 6.3 军事思想

先确认目标，建立可靠接战面，再用火炮、工程支援与预备队完成战斗。

正典的优势在体系完整：兵种容易配合，受损装备能够撤回维修，主力适合调整部署。弱点是单体突破能力较克制，不能指望与重锤重装在相同条件下长期正面对射总能获胜。

坦克拥有独立炮塔，并保留边移动边瞄准开火的表现。机动与协同是性格，不需要强制引入繁复阵型、士气或额外宗教资源。

## 6.4 美术与固定基础配色

- **固定基础色：**原设计的大块蓝漆、奶油白、纸板切边与深灰棕结构件继续保留。
- **结构语言：**拱架、斜撑、梯形底座、整齐拼缝、清楚的装配编号。
- **徽记：**原有翼形／展开旗形符号，可结合几何基准线。
- **材料状态：**有使用痕迹，但维护认真，修补位置具有结构理由。
- **玩家所属：**另外设置醒目的独立识别区，不能把固定蓝色当作玩家颜色。

正典即使面对另一支同样以蓝漆为底色的正典部队，也应通过玩家识别区、旗帜底色和所属标记清楚区分。

## 6.5 建筑气质

这些建筑可以共享构造语言，但不能共享同一套“小屋＋窗户＋屋顶”的主体。

# 7. 重锤军团

## 7.1 身份与口号

> **“让胜利作证。”**

重锤军团相信，能决定结果的力量才有资格决定秩序。

它拥有强大的重工业，把集中生产、突破防线与占领工业区视为最有效的统一方式。在默认战役里，它是更明确的扩张者，会征用矿区、强制接收工厂并销毁抵抗者的战争能力。

它的危险不是单纯好战，而是一套要求持续获胜的制度：胜利证明神授统治，因此停滞与失败都可能威胁统治本身。

## 7.2 信仰与制度

创造者被称作“巨手”。孩子关于更大、更厚、更厉害的偏好，被军团解释为力量天然具有裁决资格。

锤是军团后来发展出的宗教与工业符号，象征通过力量给材料赋形，不要求创造者真的拿锤子制作模型。

生产纪录、验收射击与凯旋仪式具有宗教意义。完成一批坦克，是工业成绩，也是神授力量再次得到证明。

军队并非不懂战术的莽夫。它尊重炮兵、维修和生产人员，能够照顾本国士兵，却通过制度把这些忠诚用于对外征服。

## 7.3 军事思想

炮火压制、装甲突破、步兵与防空保护、占领后继续扩张，是重锤的理想流程。

优势在正面压力、装甲厚度和攻坚能力；弱点在转场、经济投入和支援要求。失去侧翼保护的炮群、脱离掩护的重坦、过长的推进路线，都应当有实际风险。

重锤坦克同样拥有独立炮塔和移动开火。笨重来自机动、转场和部署特性，不应通过故意制造输入迟钝来表达。

## 7.4 美术与固定基础配色

- **固定基础色：**原设计的大块暗红漆、黑褐底盘、灰褐纸板与裸露切边继续保留。
- **结构语言：**低伏楔形、方头、粗履带、厚压梁、多层装甲与夹固结构。
- **徽记：**独立设计的锤形与工业框形符号。
- **材料状态：**强调冲压与叠层，不靠写实金属反射制造重量。
- **玩家所属：**另外设置醒目的独立识别区，固定红漆不等于敌方颜色。

不能只把正典资产放大后改成红色。重锤需要不同的重量分布、开口方式和设备轮廓。

## 7.5 建筑气质

总部以厚支撑与压梁形成地标；载具工厂是横向生产线；维修站是开放夹臂检修床；指挥中心是较细高的号令装置。

阵营统一不等于所有建筑都成为重型车库。内部也必须形成高低、空实、横向与纵向的差异。

## 7.7 代表人物

**铁拳将军**：擅长组织攻坚，尊重能够完成任务的部下，也知道保护炮兵和生产。他把征服解释为尽快结束争议，因此能认真相信自己在制造秩序。

> “炮兵发言，装甲前进。”

他不是因为模型小而显得可笑；荒诞来自他确实把炮火当成有法律效力的意见。

# 8. 铁钉同盟

## 8.1 身份与口号

> **“结实的东西，才值得托付。”**

铁钉同盟是由冶炼城市、工务基地和军工共同体组成的工业势力。它像认真、固执、重信誉的工匠，对自己的制造水平自豪，认为装备与战友都值得认真维护。

持钉者是一个特别在意模型牢不牢的孩子。他会检查车轮有没有松动，给承重位置再粘一层厚纸板，把损坏的位置重新固定，并说：

> **“放心，不会散架的。”**

军团把这句话理解为创造者的承诺，也把它当作交付者的责任。它保留近现代坦克、飞机、工厂与电磁武器，不另加奇幻种族、符文或中世纪工坊。

## 8.2 信仰与制度

铁钉的信条是：**造出来，就要经得起用；交出去，就要对它负责。**

最受尊重的人能够证明：车辆经受炮击后还能带回乘员，桥梁能够承受重装备，飞机能够完成往返。质量保证被严肃地提升到宗教高度，而维修是照顾战友与设备的日常职责。

各工业城市保留自治，由共同制造标准、工程承诺与军工调度组成同盟。它的矛盾在于，认真负责有时会变成过度保守：工程师要求安全检修时间，前线却需要立刻推进。冲突围绕责任与保障，不围绕拒绝让任何造物结束。

## 8.3 军事思想

铁钉维护主力，保持支援体系完整，以稳定推进和挽救受损设备降低消耗。与重锤的厚前甲、重炮和决定性突破相比，铁钉强调结构耐久、可靠底盘和明确维修支援，爆发较克制，维修必须付出资金、时间与安全位置。

**通用备件**采用统一接口和模块护板，使用现有资金。工兵负责建筑与基础修复，扳手维修车负责野战载具保障，露天检修站负责高效整修，机场负责飞机维护。多个维修来源不叠加。

**战场救援**服务于仍存活但处境危险的友方载具。拖救车保持近距离护送，帮助低生命载具加速撤离，随后交给维修。当前使用简化护送表现，不需要复杂绳索物理。

**加固改装**可作为后续选择：加固组件提高生存并牺牲机动，机动组件改善转场与撤离。两种方向应有明确取舍，当前不承诺已接入可选改装。

## 8.4 美术与基础配色

- **基础色：**赭黄色维护面板、石墨结构与灰棕工装，保留底纸和必要修补痕迹。
- **结构语言：**厚纸板、宽履带、短宽车体、牢固炮塔座、标准固定件与整齐护板。
- **徽记：**钉形与连接环，象征连接可靠与工艺责任。
- **工艺表现：**补强位置可信，胶接清楚，工具和备件有秩序，设备受到认真维护。
- **玩家所属：**使用独立识别区，保留固定基础涂装。

铁钉应像一个认真做质量保证的孩子，用更厚纸板、更结实连接和更多耐心拼出的军团。普通士兵穿工业防护服或宽厚护甲，不使用呼吸改造、缝合、奴役或亡者意象。

## 8.5 建筑气质

总工坊以厚底座、四角支撑和低调度台建立工业核心；前线工坊是简化同族结构。锅炉发电站使用卧式锅炉、粗管路与飞轮；筛选精炼厂使用料斗、滚筒筛和宽卸料口；守备兵营具有结实营房、装备架与训练区。

# 9. 天翼教团

## 9.1 身份与口号

> **“想象即是现实。”**

天翼拥有航空工业、能源研究与试验基地，掌握真实的先进技术，但外观像想法很多、手工做得很快的孩子拼出的军团。续绘者把纸筒粘在盒子上，画两条线，就宣布它是电磁炮。

> **“里面是高科技，你又看不见。”**

简陋的是外形制作，武器功能依然真实。神授原型能够获得先进能力，但必须消耗资源、电力与时间，遵守射程、伤害、机场和防空规则。

## 9.2 信仰与制度

续绘者剪出不完全对称的机翼，面对纸盒长翅膀的质疑，会说：**“因为先进，所以才这么简单。”** 教团将它理解为技术启示：先进设计不受传统外壳形式约束。

研究人员、军官和飞行员专业地组织生产与战斗。歪纸板天线被正式称为“非对称多向观测组件”，露出的胶接带被称为“外置结构稳定层”。荒诞来自庄严解释，不来自随机失灵或每次开炮都有概率自毁。

教团的矛盾在于对新功能太有信心，可能把结构检查和前线使用条件视为拖延。制度仍要确认试验结果、能源与维护需求，不能把创造者的口号当作无限能力。

## 9.3 军事思想

天翼观察目标，集中打击，选择出动和增压时机。它拥有完整地面军队和工业骨架，先进武器从朴素矿车、工兵与运输设备中脱颖而出。

**目标标定**由纸板观测架提供真实火控，需要距离、视线与持续跟踪。**局部蓄能增压**由纸筒电容组提供短时伤害窗口，需要资金、电力余量与重新充能。**航空机动**执行制空、攻击与运输，受防空、机场机位与补给周期约束。

科技准备、能源依赖、设备成本与较脆结构形成取舍。不能同时给它廉价厚甲、最强持续火力，或临时推翻共同战斗规则的神谕。

## 9.4 美术与基础配色

- **基础色：**象牙白、靛紫与蓝灰，涂装有刷痕、底纸和不完全整齐的分界。
- **结构语言：**少量大纸盒、粗纸筒、厚折板、手画设备线与明显胶接。
- **手工表现：**允许切口略歪、贴合不齐和少量不对称，主要部件连接牢固，功能和朝向一眼可认。
- **关键效果：**少量先进武器在充能和开火时出现克制的导轨亮线或脉冲，不给所有表面铺发光纹。
- **玩家所属：**在大纸板或盒体上保留清楚的独立识别区。

一个坦克可以由厚盒车体、两条履带盒、方炮塔与粗纸筒构成；飞机可以由扁盒机身、一张厚板机翼与纸筒发动机构成。纸板厚度、切边、折痕、胶接、光照和阴影必须做好，让简陋模型仍像真实手工成品，不靠无意义小零件遮掩。

## 9.5 建筑气质

展翼总部是宽扁厚纸盒、展开的大折板和手绘星图板；前线翼站保持小型同族结构。励磁发电站使用两根粗纸筒、方底盒和简化线圈；辉晶分离站使用斜滑槽、直立分离筒与开放卸料口；勤务兵营是低长营房与集结区。

试制工厂使用大平板装配床、三角支架与开放滑轨；校准维修台是开放十字地台和弯折厚板检验臂；航务指挥台立着折扇形天线；续稿研究所以两只不等大的纸板试验环和中央方测试箱区分。展翼机场有平板跑道、手画引导线与折叠机棚；蓄能站用粗纸筒捆成电容组，下接低方盒。

# 10. 阵营关系与同阵营战争

## 10.1 四方关系

| 关系 | 根本分歧 | 可产生的故事 |
|---|---|---|
| 正典—重锤 | 合法标准与武力裁决谁更有权威 | 正典拒绝未经认可的接管，重锤认为不能贯彻的标准没有意义。 |
| 正典—铁钉 | 按图认证与交付责任如何划分 | 正典要求统一记录，铁钉坚持维护方案必须由实际承担质量的人确认。 |
| 正典—天翼 | 合法修订与外壳不受传统限制的功能 | 正典要求证明连接和标准，天翼认为粗纸盒也能承载神授先进技术。 |
| 重锤—铁钉 | 决定性突破与保障体系完整 | 重锤要求立刻推进，铁钉坚持保留维修、撤离和人员安全通道。 |
| 重锤—天翼 | 已验证的力量与尚未完成的性能承诺 | 重锤轻视纸面优势，天翼试图用新技术越过厚甲。 |
| 铁钉—天翼 | 连接可靠与功能先进哪项先验收 | 铁钉检查新炮座的固定带，天翼认为这只是不重要的外置稳定层；两方仍需要彼此的工艺与技术。 |

各方都可以临时合作，但没有永恒的正义联盟。理解阵营动机，不等于认可其全部行为。

## 10.2 同阵营之间为什么也会交战

“阵营”代表共同的教义与制造体系，不等于只有一个永远统一的指挥机构。

同阵营战争可以来自：

- 对同一句神谕的解释或认证版本不同；
- 军区争夺辉晶矿区和工业调度权；
- 总部授权、继承或圣遗械所有权存在冲突；
- 内部叛乱、分裂或演习模式。

因此，两支正典军团使用相同蓝色基础涂装、相同型号与相同徽记，并不矛盾。区分双方的是独立的玩家／军区识别色和所属信息。

不必为每一场遭遇战写完整政治背景。上述设定提供世界内的可能解释，玩法本身仍可自由组合。

# 11. 建筑体系与形态规则

## 11.1 通用功能骨架

四个阵营都应当能完成采集、供电、基础训练、载具生产、维修、航空与科技发展。身份差异通过设备结构、节奏和兵种侧重出现，不靠某一方缺少全部基础工具实现。

| 功能 | 设定与设计规则 |
|---|---|
| 总部 | 战略指挥、建设授权与核心档案；具有阵营地标感。 |
| 前线分基地 | 总部的缩小同族建筑，用于扩张；不能只有模型小旗而失去识别。 |
| 兵营 | 训练与集结，允许营房、宿舍或训练场式结构。 |
| 发电站 | 电力设备决定轮廓，不只是房子上放两根烟囱。 |
| 精炼厂 | 料斗、分选、压碎、容器等决定轮廓。 |
| 载具工厂 | 合并普通与重型载具生产，通过科技解锁，不再额外制造高度重复的重型工厂。 |
| 工程维修站 | 开放式平台、吊架、夹臂、检修床；不得重新变成封闭大车间。 |
| 指挥中心 | 战术通信、协调与侦察相关功能；与总部在高度、平面和主设备上显著不同。 |
| 研究所 | 实验装置决定外形，与总部及指挥中心区分。 |
| 机场 | 飞机生产、停靠或出动；跑道、停机区与管制设备可读。 |

## 11.2 首发两方的主要建筑轮廓

| 建筑 | 正典军团 | 重锤军团 |
|---|---|---|
| 总部 | 宽底盾形／梯形底座、中央旗座与两侧斜撑 | H 形厚支撑、压梁与中央锤印 |
| 分基地 | 总部的简化底座与短旗座 | 小型压梁框架与短标记台 |
| 工厂 | 高拱门架与贯通装配通道 | 横向流水线与低矮冲压设备 |
| 维修站 | 门式吊架、开放地面平台 | U 形夹臂、中央留空检修床 |
| 指挥中心 | 低圆形战术台与半环天线 | 细高号令桅杆、广播与命令板 |
| 研究所 | 开放校准台与实验线圈 | 压力容器、试炮架与厚护板 |

**统一风格，不等于统一房型。除兵营外，优先用功能装置构成主体，不需要考虑像普通住宅一样安排门窗。**

## 11.3 与当前玩法保持一致

车辆采用有真实体积的简化 3D 纸模，而不是单张侧面贴图随角度变薄。坦克车体和炮塔独立，能够边移动边瞄准与开火。

“移动中开火”与“攻击移动命令”是不同概念：前者是武器能力，后者是输入与索敌行为，不能在实现或文案中混为一项。

建筑具有真实侧墙、顶面和厚度，但不追求写实工程。所有模型仍优先保证默认 RTS 视角下的辨识。

# 12. 基础配色与玩家识别色

## 12.1 本稿采用的最新规则

**保留各阵营原有的大块基础配色，不整体替换为玩家色。每个单位和建筑另设醒目的独立玩家识别区。**

正典可以继续大面积蓝色，重锤可以继续大面积红色。阵营名称已去掉颜色，玩家所属则由专门的标记区域表示。

这与“把整个坦克重新染成玩家颜色”的方案不同。不能在后续资产制作中无意退回全模型换色。

## 12.2 三类信息分工

| 信息 | 主要视觉依据 |
|---|---|
| 这是什么单位／建筑 | 功能结构、轮廓与专业设备 |
| 它来自哪个阵营 | 基础配色、造型体系、材料、固定徽记 |
| 它由谁控制 | 独立玩家识别色、识别旗、所属编号与界面标记 |

玩家识别色必须足够醒目，不能只剩旗尖、袖章或很小的门牌。与此同时，也不要让标记覆盖整个模型，破坏固定基础涂装。

## 12.3 标记区位置

每个资产设置一个逻辑上的“玩家识别区”。为了保证不同角度能看见，可以将同一识别区的颜色延续到顶面与侧面；不要求只有一个从侧面才看得到的孤立小面。

| 对象 | 推荐位置 |
|---|---|
| 步兵 | 可从默认镜头看清的头盔顶、上身或肩背面板；不是只有细小臂章 |
| 坦克 | 炮塔顶的专用标记板，必要时延伸至侧面识别带 |
| 矿车与装甲车 | 驾驶室顶部与可见侧板，不藏在矿物后方 |
| 飞机 | 翼面识别板、机身带或尾翼；必须考虑从上方观察 |
| 总部与工厂 | 顶部标记面、大横梁标记或立面识别板；旗帜为补充 |
| 开放维修站 | 吊架横梁、设备板或清楚的地面识别板 |

所有图纸都应明确标出哪部分可变、哪部分固定，不能让程序根据“看起来像蓝色／红色”自动猜测。

## 12.4 示例与不变项

最新展示图中的“正典蓝色基础＋橙黄色识别区”“重锤红色基础＋青色识别区”，只是一组对战示例，不是新的永久绑定。

同阵营镜像对局可以表现为：

- 正典 A：蓝色基础＋橙黄色识别区；
- 正典 B：蓝色基础＋紫色识别区。

具体可选颜色需要在真实画面中测试辨识度。与本阵营底色过于接近的颜色，可以通过识别板的中性底框、明暗对比、所属符号或配色限制处理。

固定阵营徽记的形状不变，其底板可以采用玩家识别色。水体、矿物、烟雾、爆炸与裸露纸板不跟随玩家自动染色。

## 12.5 风格与界面一致性

识别区也必须保留颜料、纸纹与边缘处理，不能像发光塑料贴片突然粘在模型上。

小地图、单位信息、选中标记和战场旗帜应与当前玩家识别色一致。不能模型识别区已经是橙色，小地图却仍默认把所有正典单位画成蓝色。

只有颜色还不够时，允许辅以简单所属图形或编号；不能用复杂纹样淹没模型本身。

# 13. 统一美术语言

## 13.1 核心目标

**像一组认真制作、涂装和使用过的纸板工业军模，放在具有真实空间体积的微缩战场上。**

不是写实军事模型，不是普通光滑低模，也不是所有物体都使用竖直纸片。

## 13.2 形体

坦克短、宽、厚，炮塔、履带和炮管具有清楚轮廓；飞机的机翼、尾翼和动力设备应一眼可认；建筑用功能装置区分，不依赖窗户排列。

简化意味着删去不影响识别的小结构，不意味着只堆基本几何体。纸浆松树可具有整体厚度、层叠枝冠与柔和凹凸，不能因为“纸板风格”就强制改回几个锥体。

## 13.3 材质与手工感

纸板身份体现在切边、层压、折痕、接缝和涂装差异。手绘感来自有方向、有位置的色块、刷痕、磨损和修补，而不是全表面均匀撒噪点。

各阵营的表面处理有差异，但共享同一种手工世界：正典整齐，重锤厚重，铁钉厚实工整且受到维护，天翼由少量盒、筒和折板快速拼成，刷痕与胶接明显。

## 13.4 光色与环境

暖色土地、较冷的水体、深绿植被、清楚的局部阴影构成共同基调。不要为了突出阵营，给四方分别设置完全不同的渲染风格。

阵营固定底色形成较大色块，玩家识别区负责归属。景深只服务微缩感，不用于掩盖模型问题或使主要交战区域模糊。

## 13.5 战争表现

炮火、烟团、弹道、受击裂片和残骸需要有节奏。破坏可以像纸模被击裂，但角色对损失的态度依然严肃。

不要把所有特效做成彩纸庆典，也不要转成写实血腥战争。

# 14. 命名、对白与幽默规范

## 14.1 命名原则

**界面名称短而好认，正式型号里保留少量一本正经的荒诞。**

例如界面写“答案坦克”，详细说明写“标准答案式主战坦克”；界面写“理由炮”，文件中写“充分理由式攻城炮”。

普通矿车、工兵、兵营不必都制造笑点。留出正常语言，标志型号才有反差。

## 14.2 角色不主动解释笑话

角色知道自己在做什么，并相信这些名称合理。不要频繁自嘲“我们只是纸片”，也不要让人物使用脱离世界的现代网络梗。

铁钉的“可靠保证式主战坦克”是一项整个工坊愿意承担的承诺；天翼的“非对称多向观测组件”则是对歪纸板天线的正式技术解释。幽默保留在少数正式名称与对白中。

| 正典工兵 | “检验通过，可以承重。” |
| 重锤攻城炮 | “理由已备齐，等待提交。” |

| 铁钉拖救车 | “保持靠近，先把战友带回来。” |

## 14.4 战场对白示例

> **东桥哨：**“发现重锤炮兵，正在部署‘充分理由’。”  
> **指挥所：**“交给校正炮。”  
> **炮营：**“请确认处置权限。”  
> **指挥所：**“准许反驳。”

随后火炮开火。没有人发笑。

两方工程人员也会严肃地争论同一件装备：

> **铁钉工程师：**“你这炮座只有两条固定带。”  
> **天翼研究员：**“这是外置结构稳定层，足够先进。”  
> **铁钉工程师：**“先进我相信。先让我再加一条。”

## 14.5 情绪基调

幽默不能让一切后果失去分量。角色之间可以有信任、牺牲、误解与责任。剧情的温度来自对小人物的认真，而不是不断提醒玩家一切只是玩具。

# 15. 首发故事与制作顺序

## 15.1 首发双阵营

优先制作正典与重锤：可承接已有蓝红资产，同时形成工程协同与重装突破的区别。

战役开篇仍聚焦正典与重锤。铁钉和天翼可以通过工程档案、保障人员和试验航班逐步进入故事；当前可选阵营与单位扩展不要求同步完成四套战役。

## 15.2 首发故事：《无字桥》

无字桥连接辉晶矿区和两侧工业城，最早的通行文件没有署名，因此长期被共同使用。

正典依据维护和检验记录主张管理权，重锤依据新的接收命令要求控制。文件争议只是引线；矿运能力、桥头分基地与工业路线才让双方不断投入兵力。

| 阶段 | 剧情 | 主要游戏内容 |
|---|---|---|
| 按图守桥 | 正典恢复基地运转，应对重锤先遣队 | 采矿、电力、基础建设与地面交战 |
| 补充理由 | 重锤炮群部署，双方扩充桥头阵地 | 火炮、装甲、防护与侧翼行动 |
| 获准升空 | 航空兵介入，后方设施受到威胁 | 飞机与防空同时引入 |
| 最终解释 | 研究设施打开高级装备，争夺关键工业节点 | 顶级科技与完整基地战争 |

胜利来自工业、指挥与战斗，不来自突然召唤造物神清空敌军。

## 15.3 四方长期故事

铁钉可以在双方争夺机修走廊、撤离通道和工程质量责任时登场；天翼则通过朴素外壳下的新航空技术、目标标定和神授功能认证争议进入主线。

后期争夺“原图座”：它是原始档案、战略指挥和工业基础的集合，不是一键控制世界的魔法按钮。

四方胜利可以产生不同结局：正典颁布共同制造标准，重锤宣布一切争议终结，铁钉恢复保障网络并为交付工程承担责任，天翼在胜利当天宣布下一项先进功能。

他们都认为战争已经证明自己的神谕。世界却仍保留继续变化的可能。

## 15.4 开发顺序

1. **锁定首发身份。** 确认名称、固定基础配色、玩家识别区、徽记和主要轮廓。
2. **验证少量代表资产。** 先做两方总部、主战坦克与开放维修站，再扩展全阵营。既检查不同阵营，也检查同阵营不同玩家的辨识。
3. **完成地面遭遇战。** 建立经济、建筑、基础兵种和可靠交互，不同时增加大量外围机制。
4. **加入航空与短战役。** 飞机与防空配套，《无字桥》验证叙事与玩法能否结合。
5. **加入顶级科技。** 对前面已稳定的军队提供后置选择，而不是从一开始制作全部科幻系统。
6. **统一精修与扩展。** 对四方完成详细优化、功能验证与平衡；当前铁钉和天翼单位及支援机制以补丁说明为基线。

在美术方向定稿前，以可运行、关键交互正常和真实截图对比为最小验证；不因本设定列出了未来内容，就立刻进行全部系统的深度实现。

# 16. 术语与设定边界

## 16.1 统一术语

| 术语 | 含义 |
|---|---|
| 造形诸神 | 外部制作纸模世界的孩子；角色所理解的创造之神 |
| 原图 | 最早的设计记录，可具有圣典地位 |
| 神授原型 | 首次被赋予功能与生命的模型，是后续生产的来源之一 |
| 阵营 | 共同的教义、工业与军队体系 |
| 玩家势力 | 一场对局中的独立指挥方，可与另一玩家使用相同阵营 |
| 基础配色 | 阵营资产固有涂装，如正典蓝漆、重锤红漆 |
| 玩家识别区 | 独立可变色区域，用于表示当前指挥归属 |
| 辉晶 | 统一采集资源，进入工业生产体系 |
| 异端 | 阵营对不受认可之设计、教义或指挥权的内部称呼 |
| 圣遗械 | 具有历史、原型或宗教价值的机械，不限定某个阵营必然围绕它作战 |
| 原图座 | 战略档案与工业指挥中心，不具备任意改写现实的能力 |
| 最终定稿战争 | 四方争夺共同正统的全面战争，也是世界观工作标题的来源 |

## 16.2 当前不采用的方向

- 森林部落、自然聚落与工业军团并列成为主要可玩阵营。
- 现实国家、现实宗教或现实政治运动的一对一映射。
- 神随时下场，把失败直接改写成胜利。
- 全部损失自动重置、没有个体后果的玩具战争。
- 为表现宗教而新增大量与现有经济重复的信仰资源。
- 所有建筑都是小房子，再用不同屋顶或图标区分。
- 仅通过蓝红换色区分两个阵营的模型。
- 仅通过阵营固定蓝红色判断敌我。
- 把玩家色染遍整个模型，取消用户要求保留的大块基础涂装。
- 为每个单位强行堆叠拗口的宗教官僚名称。
- 让科幻阵营脱离纸板结构、工业生产与共同玩法限制。

## 16.3 后续仍需确认

- 四阵营模型在真实战场尺度下的持续辨识与材质优化。
- 完整单位数量、生产前置、战役长度与具体数值。
- 分基地扩张权限和总部存续判定的最终规则。
- 可选改装、闸门操作、额外侦察和战役专属功能的实现范围。现有维修、救援、标定、增压与运输以补丁说明为准。

这些未定项不影响首发正典与重锤的世界观和主要美术方向。

# 17. 游戏简介文案

## 17.1 完整版

门关上时，诸神留下了四套图纸。

每一套都写着正确的形状。每一套都有自己的坦克、工厂与天空。

正典遵循原图，重锤宣读裁决，铁钉承担质量保证，天翼用朴素纸盒实现先进想象。

辉晶被装进货舱，电流穿过圣堂般的装配线。飞行员在起飞前确认自己的版本仍然有效，炮兵则为没有结束的争议准备新的理由。

现在，他们需要一场胜利，证明其他图纸从一开始就是错的。

**开采资源。扩大生产。击败异端。**

**愿最后留下的那份图纸，恰好属于你。**

## 17.2 简短版

几个孩子拼出了军队。军队建立了工业、信仰与历史，并认真相信其他孩子的设计都是异端。

指挥你的纸板军团，开采辉晶，建设基地，让坦克、大炮、飞机与试验武器证明哪一套图纸才有资格成为最终定稿。

## 17.3 一句话定位

> **一场发生在手工纸板沙盘上、由工业军团严肃执行的造物神权战争。**
