## 推荐下一轮与保留条件

G0 已实现并冻结，比例/silhouette 检查确认当前车辆无需继续缩放。已保留 v01c 道路/路肩、v02b 屋顶配色、v03 阴影滤波和 v04 崖壁墙身的局部改善。v05/v05b 模型刷色在整图改善不足，已回退；v06b 树冠大形和 v07 暖主光/填充比也已保留为局部改善。v08 平台内道具未改善环境组织，已回退；v09 模型墨线读形改善，已保留。重新评估固定道具锚点后，下一轮优先只处理 **岸顶与崖壁上沿的规则轮廓**，继续以当前 G0 判断。环境密度、林缘和残留地面斜纹仍待后续处理；这些小步尚未解决整图空旷，也不代表整体风格定稿。

这一排序依据当前截图；用户给出的①比例②palette③光影④材质⑤地图⑥特效仍作为完整检查清单。若 G0 显示比例问题比当前样本更严重，就以新证据重排，并记录原因。不是预先批准大规模环境重构：崖壁、树林、props、水面各轮分别处理。

每轮将参考图、上一张 G0 和新图并列观察三个固定区域：全图构图/色块；桥头车辆、步兵和道路；基地建筑、屋顶、林缘与接触暗部。可以额外查看等比例局部，但不能更换主镜头或只展示局部避开恶化区域。结论用“改善 / 无明显改善 / 变差”及可见原因，不编造相似度百分比。

若首轮的新路迹太规则、装饰抢过部队、道路像刚铺的亮白线，继续缩小到同一维度调整；不要顺手改屋顶、太阳、树高或烟尘。保留结果须同时满足目标差距缩小和关键可读性未损坏。
