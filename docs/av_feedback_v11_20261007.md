# 2026-10-07 试玩反馈修订

当前源码使用仓库根目录 `./run.sh`。本轮修改游戏代码与本地活动资源，历史发行归档保留。

## 结算与镜头

作战结算改成原游戏窗口内的全屏 Control 页面，取消独立 Window。结束时收回模拟线程、冻结模拟、禁用战场 SubViewport 并隐藏战场画面，结算仍使用实际统计。菜单、新战局、退出沿用正常流程；新局与读档恢复战场显示。数字/表头使用24逻辑像素、标题48像素，跟随游戏画布缩放，小窗口额外补偿到至少18实际像素；表格滚动，不通过缩小字体硬塞所有行。保留一个原有 FPS 层。

相机以实际局部地形为目标，增加前视高度包络和限速缓动；额外提前量抵消滤波迟滞，安全净空仍保留。平移跨悬崖时不直接跳到下一格高度，远方高山仍不控制近距缩放。显式定位/开局姿态直接设置。实际320森林最大15.6米相邻高差测试：60Hz受控平移最大单帧升降0.333334米、最小局部净空2.183487米；这是冻结模拟的渲染/轨迹检查，不是帧率基准。

## 声音

总音量、音乐、音效、语音默认全部100%，上限200%。原完整默认组合迁移到100%，识别到自定义组合则保留。分类基础增益保留旧默认有效参照：voice0.7225、SFX0.765、music0.3825；战斗声音源再降低20%，避免调成100%反而变响。

四阵营×步兵/车辆/空军使用十二个不同基础演员，组合 MAI、Grok、Qwen。每组七类正常情境各三句、阵亡四句，共300条；同单位各动作固定演员、pitch1。铁钉空军Lan与天翼空军Sal分别为轻女声/低中男声。已修复确认的拖长与多音词问题；不支持音素控制的接口采用明确上下文或换词，不把SSML当正文读。

选中/下令多个同组步兵时，只选择一次实际台词与变体，最多三人按0/50/100毫秒错时应答，共用三路语音预算。已接受的玩家群体应答替换两路战斗叙述，正在进行的玩家命令保留并排队；慢帧通过播放位置补偿延迟差。语音三路上限不影响环境音：独立24路场景声池及三个聚合移动底层，附近双方都有声音，迷雾外敌方移动声排除。

界面提示只保留建筑电流选中和轻按键，其余九个重新制作。出售改成机械纸板收折。天翼能量武器及创世之手各有独立发射/命中三变体，按真实武器路由，并提供对应静音演示。

重制菜单、无战斗舒缓、克制交战、危机四首音乐，保留激烈曲，活动音乐共五首。各地图无战斗及结果页面共用新舒缓曲。近十秒内真正开火的存活单位按敌我分别计数：己方至少六人进入激烈层，敌方至少五人且己方零人进入危机层。第三层锁定，直到双方真实交互停止超过五秒才退出或互换，清理旧记忆防止立即跳回。音乐仍各两秒淡出/淡入；玩家暂停冻结游标、淡化及分类时钟，恢复原位置。暂停中的试听往返、曲目淡化中的试听往返也保持原游标/淡化阶段。

活动目录381项：300单位语音、2系统警报、74音效、5音乐；旧UI/背景曲及实验素材不显示。[音频说明](revision_v8_audio.md)记录声线、加工、方法、真实来源和费用。

## 飞行与创世之手

飞机使用实际视觉高度提前爬升/缓降，尾迹按真实高度连续倾斜。以前24米前视在20米悬崖可能产生6.63米单帧突跳；现依据缓存地形跨度和升率扩大前视，并保留安全高度。真实森林及14.8/16/20米崖、8/12米每秒飞行的17项测试全部通过，30Hz最大高度变化0.173333米。

飞行单位死亡保留原模型，按真实水平速度/方向带浓烟惯性下坠，接地后产生碎片；不增加模拟伤害。近/远/超远网格、可见性和数量上限保留。射击和空中弹着、选择投影使用视觉高度，逻辑高度和武器协议不改；音频浏览器空军阵亡演示也改成静音坠落。

创世之手腕部色带、手背标记和指甲增加玩家势力色，原皮肤、共享网格、Skin及16骨架保留，所有LOD可辨。[飞行与势力色验证](aircraft_visual_20261007.md)保存420项飞行、17项陡崖、34项手部检查和14张实机图片。
