# 第二轮反馈修正与验证 · 2026-10-02

## 修正

1. 矿车旧货箱的内部盖板和外框顶面同处 y=1.56，存在大面积共面深度冲突。改为开放货箱、独立侧板和较低箱底；保留随货物数量增减的矿石。实际截图包括空载、半载、满载。
2. 选中矿车右键矿点生成持久采矿命令，满载交付后记住并返回指定矿区。停止取消采矿；Shift 追加的后续命令在本轮交付后执行。采矿接近点分配到矿点周围，避免所有矿车争抢中心。
3. 死亡火团分批出现、持续约一秒，另有飞散碎片、约三秒黑烟和短时焦痕；普通落点火团仍是不到半秒的低火团。中立废墟摧毁使用尘烟和碎片。
4. 压力场景先生成双方建筑，再分配命令终点；拒绝生成地图外建筑。普通命令在终点被新建筑覆盖后重新选择附近位置；为密集编队保留不同终点，避免因为暂时被其他单位占用就丢弃命令。让路任务会超时，单位保持避让方向，车辆可倒退和缓慢转弯移动。加入行进方向的侧向间隔、已绕过拐点的跳过，以及按真实半径检查 AStar 相邻点之间整段通行宽度的缓存。
5. 新地图移除孤立的旧石块/石柱，生成镜像分布的废墟簇，每簇为一座带窗洞的半毁厚墙建筑和两段带木柱的低石墙，辅以破损边缘、色块、细裂纹、倒木梁及碎砖。低墙约 0.8 米，残墙最高约 2.4 米。它们是中立障碍，可用武装单位右键攻击，左键查看生命；摧毁后开放占地通行，存档保留生命与摧毁状态。手工图种子 73026 生成 20 簇、60 个独立可摧毁部分。

旧存档保留原地图，新增成簇、可破坏废墟需开新局。玩家可建造的防御围墙/拒马保持原有独立规则。
