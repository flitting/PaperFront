# 建筑原图对照与修复方案

2026-10-02。依据用户提供的正典军团、重锤军团示意图，以及本轮对“体量太小、只有骨架”的反馈。两张图片和最新反馈是本轮视觉验收依据。

## 问题定位

上一版过度强调阵营轮廓差异和开放式工业设备，误把可使用的建筑改成了工业符号：总部变旗座或压机、兵营变拱肋、工厂变门架、科研楼变线圈台、通信楼变圆桌或广播杆、机场变裸机棚。

原图多数对象具有完整的主楼、屋面、侧墙、附楼及实体设备。开放式维修站也有厚吊架、检修床、机修模块与工具柜，不能只剩吊钩和框架。

现有底座宽度约为规则占地的92–95%，所以“显得小”首先是有效实体缺失。修复先填足既有占地中的实体体量，提升主体墙高和屋顶厚度；整体改变占地需要同时调整建造、碰撞、采矿与生产出口，本轮优先避免这些无关的玩法变化。

## 验收办法

1. 先修两方总部、工厂、维修站六个代表，对照原图、修复前和修复后。方向通过实际视图检查后再完成其余建筑。
2. 使用固定世界尺度、相机和入口方向，旁放当前坦克与纸兵，禁止为单个建筑拉近镜头掩盖体量问题。
3. 除维修站、守塔与机场露天坪外，主体及附楼初步按底座顶视面积约55–75%构造，主要入口相对纸兵应有可信高度；旗、天线与底座不算主要建筑体量。
4. 直接测实际网格的有效实体占地和净实体体积，重叠几何不重复计量，保持实际模型不越过规则占地。机场单独检查机库，不能用跑道面积代替机库体量。
5. 每个角色具备原图中的三个结构锚点。例如研究所“楼体＋穹顶＋仪器塔”，机场“实体机库＋塔台＋停机坪”，指挥中心“控制楼＋雷达碟＋通信构件”。
6. 完成后更新单独模型、真实模型生产图标、对照截图和运行包；检查独立炮塔、枪口、点选、烟囱特效及关键玩法。

修复前源与截图保存于 `artifacts/building_repair/before`；本轮前后对照和体量测量保存在 `artifacts/building_repair`。载具及纸片步兵的几何保持当前版本。

## 本轮修复结果

22种核心建筑已完成主体重建。真实有效实体占地均值由 24.9% 提高到 58.7%；净实体体积由 78.81 增至 250.41 世界单位³，中位数增长 3.63 倍。这些结果来自固定尺度下的真实网格并集，排除底座，不把重叠盒体重复计量。
