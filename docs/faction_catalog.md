# 四阵营单位与建筑目录

依据[四阵营世界观与美术设定 v4.1](派系设定/paper_front_world_setting_four_factions.md)及当前 `data/rules.json` 生成。运行 `python3 tools/document_faction_catalog.py` 可更新数值表。铁钉与天翼的设计修订和机制边界见[扩展说明](expansion_factions.md)。

## 身份与资产

正典军团、重锤军团、铁钉同盟、天翼教团均为当前可选阵营。固定基础配色与独立玩家识别区共同保留：正典蓝漆、重锤暗红漆、铁钉赭黄与石墨结构、天翼象牙底纸与靛紫刷痕。选择圈、血条、小地图及模型识别区使用所属玩家色。

稳定内部 ID 为 `kestrel`、`rivet`、`iron`、`sky`，单位重命名保持既有引用兼容。旧存档自带规则快照；当前规则用于新开对局。

当前目录共 **69 种单位、60 种建筑、56 套武器**。模型类别为 **115 个实体建筑／地面载具／飞机／舰艇条目、1 种连续皮肤蒙皮巨手、13 种纸片步兵**；这些是目录条目分类，不是网格或骨骼数量。步兵保留五状态切边与玩家识别遮罩，铁钉与天翼保留可靠工业工艺与简陋纸盒高科技构造。数值是当前规则基线，持续平衡以对战结果为准。

创世之手现使用 MakeHuman Community 的 CC0 图形基础网格裁出的连续手部皮肤，通过 GLB、Skin 与 16 骨 Skeleton3D 变形；五指不再以13块刚体拼接。骨数是当前美术资产说明，不是玩法限制。只使用图形网格，没有把 MakeHuman 应用程序代码纳入游戏；[来源与许可](../assets/creator_hand/README.md)、[官方资产许可副本](../assets/creator_hand/MAKEHUMAN_LICENSE_ASSETS.md)及[来源校验记录](../assets/creator_hand/source_provenance.json)随源工程保留。

## 阵营作战机制

机制说明与游戏阵营卡、单位介绍共用 `scripts/faction_trait_text.json`，参数来自当前规则。铁钉与正典的全军特性仅作用于单位；重锤突破作用于地面与海军的武装装甲单位；天翼EMP由断流车的武器触发。

| 阵营 | 当前机制 |
|---|---|
| 正典军团 | 正典作战单位在5格内有至少2个其他同域友方作战单位时，伤害提高8%；装载中的单位不计入。 |
| 重锤军团 | 重锤武装装甲车辆在攻击移动中累计推进5米后，4秒内下一次开火伤害提高20%；开火后重新积累。 |
| 铁钉同盟 | 铁钉单位受到的伤害减少10%；停止开火且未受伤6秒后，每秒自动恢复最大生命的1.2%，装载期间暂停恢复。 |

## 空军、维修与运输

飞机从机场生产，具有空中高度和独立飞行移动，可越过地面障碍。截击机与防空车只对空；攻击机、轰炸机与其他武器遵守各自空地目标配置。有限弹药耗尽后自动返航补给，也可按 B 返航；机场损毁后寻找备用机场，缺少保障时进入等待状态。

| 阵营 | 每座机场机位（含生产队列） | 停机维护速度 |
|---|---:|---|
| 正典军团 | 4 | 16 生命/秒，按实际恢复付费 |
| 重锤军团 | 4 | 16 生命/秒，按实际恢复付费 |
| 铁钉同盟 | 4 | 18 生命/秒，按实际恢复付费 |
| 天翼教团 | 6 | 12 生命/秒，按实际恢复付费 |

工程兵施工、基础修理和桥梁作业继续使用统一规则。维修站通电后付费修复范围内地面装甲；多个维修来源取最高速度，不能叠加。扳手维修车、检验车与吊装工程车右键受损己方地面载具后靠近维修，不修复步兵、建筑或飞机。费用沿用现有资金体系，不添加零件资源。

当前维修费用为 **0.2 资金/恢复生命**。机场停机维护同样按实际恢复生命付费；低电停止维护。飞机弹药补给按机场与出动周期进行。

右下第三格为「装载/卸载」两动作菜单。装载时先选己方载具再点地面步兵，或先选步兵再点载具；包括工兵和反甲兵，有余位可继续补员。菜单显示空位/人数，未选有运输资格的对象时禁用；具体容量按单位条目读取。卸载动作或 U 后左键指定合法空地/登陆海岸，载具到达后下客；也保留当前位置卸载按钮和步兵右键己方载具登乘。运输机 L 后左键指定合法空地降落；B 主动返航维修补给后停机，移动命令重新起飞；自动弹尽返航保留原任务，服务完成后恢复。

四阵营船坞直接建在海面上，全部占地须为水域，并保留可出航及往返登陆海岸的通道；仍受己方扩建/港湾权限与前置约束。运输船只能在合法海岸登卸步兵。旧存档保留旧规则中的岸边船坞位置，重新开局使用全海面选址。

## 科技流程

先选择己方已完成总部/分基地，下方显示当前已解锁的常规与防御建筑；两类订单仍各有独立队列。选择兵营、工厂、机场或船坞时，只显示该设施能生产的单位，并把订单放入所选设施的独立队列。不选对象、仅选单位或非生产建筑时，下方建造栏隐藏。

科技前置、阵营或生产资格不满足的项目直接隐藏，总部不可重造。资金暂不足、队列占用或机场机位已满时，已解锁卡保留费用和状态，避免目录闪烁。选中工兵在右侧独立「部署分基地」操作中选址，可重新选址/取消，不唤起下方建筑目录；抵达后施工并随进度付款。

总部 → 电站 → 精炼厂与兵营 → 载具工厂 → 维修站／指挥中心／研究所。机场、船坞及高级装备按各条目的前置开放。下表的「地/空/海」读取武器 targets，表示攻击域，不能把单位所在的移动领域当成攻击域；例如创世之手在地面行走，其武器按当前规则可攻击地、空、海目标。以下价格、生命、攻击数值与前置均直接来自当前规则。
