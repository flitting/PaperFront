# 地图视觉重建需求

范围为六种320遭遇战地图，城市优先；保留2—4方出生点、公平矿点和正常海陆路线。重建流程：逐图AI生成完整俯视小地图，再以小地图为参考AI绘制同布局全景；保存全部提示词与图片；按地形、水系、道路、分区和地标重建真实3D场景；以同方向全图及近景截图交给独立代理比较，明确差距并修正。

城市必须从均匀重复格网改为河港、多密度城区：旧城、新城、公园、广场、住宅、铁路货场和仓储区。自然地图必须有可识别的水系、地势、植被层次、村落/营地和地标。群岛保持大片连通海域、自然海岸、岛内高低差和合法登陆点。每张设计包含四方典型布置，其2/3方变体仅调整公平出生/矿点保护区，不抹去地图主题。

目标是尽量匹配AI设计的宏观形状、地标、色彩和局部资产。绘画中的光照、材质微细节以游戏现有纸模风格落实，不用一张背景图片代替可交互地图。最终比较须区分实际完成与剩余差距，不能只凭单元测试判断视觉一致。

每张图的具体设计、坐标和提示词在briefs.json。生成器采用内置image_gen。
