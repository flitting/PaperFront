# 寻路性能回退与后台执行

## 已撤销

撤销共享群体 A* 主路线、窄口通行预约、半格图加密、递归协作微步让路，以及路径搜索中的脚本邻边回调。原群体通行代码仅供旧存档校验兼容，不再由模拟执行。保留石墙/半毁建筑美术和随机分布、航空与支援单位等后续功能。

## 当前约束

- 完整 A*、可通行掩码更新、路线简化在低优先级工作线程执行。工作线程持有自己的图，只读取不可变几何快照，不访问场景节点或实时实体。
- 主线程使用非阻塞锁领取结果；每个物理更新最多提交 2 项，最多 2 项在途。任务交换循环预算 0.75 ms。
- 局部避让预算 1 ms、最多 96 个探测和 3 次让路请求/物理更新。以上是昂贵避让逻辑的预算，不是整个模拟的 CPU 上限。
- 堵塞后延迟并错开重试；队形落点改用空间散列和有限尝试，避免大队下令时出现二次方搜索。
- 路径拐点的逐帧前视检查限制在近处，不再每帧重复检查长路段。
- 建筑或断桥变化只在主线程发布小型障碍快照，后台按版本更新；旧版本、旧命令和已死亡单位的结果不能被应用。
- 不减少物理更新频率、不修改游戏时间倍率、不降低测试分辨率。允许单位等待、走得不够聪明或暂时堵住。

存档保留实际命令、单位与经济状态。后台工作属于可重建数据；载入后重新排队。来自预约版本的 formation/traffic 状态会清除。航空继续使用独立飞行与服务逻辑，不占地面寻路任务。

## 实测

硬件与全部原始指标见 `artifacts/navigation_budget/*.json`。同一压力入口：256 移动单位＋32 建筑，1920×1080、原生画质、20°俯角。采样剔除前 5 秒。

| 指标 | 修改前 | 回退＋后台寻路，同一图形资产 |
|---|---:|---:|
| 平均 FPS | 3.38 | 29.25 |
| 帧耗时 P95 | 437.99 ms | 36.44 ms |
| 最大采样帧耗时 | 853.92 ms | 52.89 ms |
| 模拟更新耗时 P95 | 64.89 ms | 15.86 ms |
| 模拟时间 / 墙钟时间 | 7.00 / 12.16 秒 | 30.10 / 30.00 秒 |

对应文件：`before.json`、`final_same_graphics.json`。修改前的 3 FPS 已复现；回退后模拟按正常时间推进，并非靠减慢游戏时钟提高帧率。

后台版同画质测试中，主线程任务交换最大约 0.17 ms，局部避让最大约 1.01 ms；后台单次任务最大约 18.99 ms。剩余帧时间还包含渲染、单位运动碰撞、战斗与 UI，并非全部属于路径搜索。

另外重新生成了失效的松树 LOD 缓存；生成器确认基础几何不变。最终独立程序的独立复测在 `release.json`：平均 33.66 FPS，帧耗时 P95 42.84 ms，模拟时间 25.17 秒 / 墙钟 25.01 秒。该结果与以上同资产对照分开记录，不把 LOD 恢复的收益算作寻路回退收益。
