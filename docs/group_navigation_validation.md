# 群体窄口通行与纸板场景更新

2026-10-02。源码修改前备份：`artifacts/group_navigation/source_before.tar.gz`。

## 通行机制

这轮改为共享 A* 主路线和窄口预约队列，直接解决“前车占用通道，后队把它当成障碍后不断寻路”的问题。

- 战略寻路图只考虑地形、桥梁、建筑和中立障碍；移动单位不再被临时禁用为 A* 节点。动态占用由碰撞和预约处理。
- 一次群体移动共用主路线，按最大单位半径识别只能单列通行的区段。在障碍物附近添加半格节点，覆盖整格中心漏掉的两格宽车辆通道。
- 入口按接近顺序等位，相向队伍以最多 8 个单位一批交替通行。通道内预留跟车距离，后车保持路线等待。
- 预约约束也用于局部避让和临时让路，防止等待者绕进正在使用的通道。出口采用疏散区域而非所有人必须踩中的单个点。
- 目标靠近口内时，把队伍落脚点移到出口外并保留不同位置。最终落脚点被已停下的友军占用时，群体成员可以在附近合法位置收队。
- 密集停驻的友军没有整格让路空间时，使用有限深度的协作微步让路。位置仍由正常速度、地形和单位碰撞检查逐步推进，不瞬移、不穿越。坚守 H 不被推开。
- 保存通行队列、占用者和阶段；取消、死亡、恢复命令及拓扑刷新均处理预约。静态拓扑刷新时优先排出口内已有单位。
- 旧存档的移动命令在载入时加入新调度；界面等待状态显示“排队通行”。自动采矿的局部移动仍沿原采矿流程，遇到正在预约的通道需等候。

“共享主路线一次”指群体层的规划次数，不表示每个单位的局部接近都不需要路径规划。

## 场景资产

- 石墙和半毁建筑分别随机成簇，一簇只有一种类型；移除固定的“建筑＋两段墙”搭配。
- 位置与方向由地图种子确定，同种子可复现；保留双方对应的场景分布及资源、道路、出生区域的净空。
- 石墙采用参考图的低矮三层石块与端部木柱。半毁建筑保留厚墙、窗洞、破损墙顶、倒木梁与碎砖。
- 改用暖米色纸面、赭色切边、棕色手绘描线、哑光纸纹与干笔色块；无石材高光、金属反射或凹凸贴图。
- 中立资产仍可攻击、摧毁、开放通路并保存摧毁状态。旧存档保留地图布局；新的分开随机分布需要新局。
