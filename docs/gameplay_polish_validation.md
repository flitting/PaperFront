本轮按用户十二项要求更新，详细操作见 README 的同日更新节。源码修改前备份：`artifacts/gameplay_polish/source_before.tar.gz`。数值仍以 `data/rules.json` 为准，独立程序由 Linux preset 导出。

## 行为和模型

- 新增两阵营围墙、拒马，共 18 种建筑。已完成防线可以直线自动补齐 1–6 格；所有格检查成功后一次扣除额外费用、生成建筑。不能跨越单位、矿点、水面、坡道或其他建筑。
- 拒马对步兵可穿越、速度为正常值的 35%，对车辆不可穿越；寻路图和逐步碰撞采用一致分类。围墙阻挡双方所有地面单位。
- 车辆车辙采用共享材质批次、最多 1800 条、5 秒自动淡出。爆炸使用短暂火团和低冲击圈、烟雾；车辆和建筑死亡使用模型高度定位火团，避免被模型遮挡。出售不触发爆炸。
- 弹道使用低拱抛物线，8 米射程额外拱高 0.36 米，真实炮口和伤害落点保持一致。
- 矿车采矿时旋转采矿头并轻微振动；货物为 0%、50%、100% 时分别显示 0、6、12 块矿石。
- 石块批次保留地图原占地，渲染为残墙和半毁建筑；散碎石改为碎砖。斜坡共用土地的基色与混色规则。
- 绿色扩建范围和六格延伸标记、金色炮塔射程圈，提示框改为浅色纸面深色字和中文前置设施名。
- W 路径点、G 往返巡逻、S 停止、H 坚守、A 进攻移动、F 定位；P 暂停 PVE。修理/出售移到选中建筑说明区。建筑卡片滚轮横向浏览，生产堵门提示“等待出口”。
- 拥堵恢复：混合编队统一间隔并预留不同目的地；允许已有重叠逐步分离；检测原地转向/局部停滞后规划避让局部拥堵的路径；H 坚守单位不被自动让路。

## 后续输入规则（2026-10-02）
