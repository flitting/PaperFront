## 矿车与经验

矿车按B或右键己方已完成矿厂，可带着部分矿立即回厂。仍需实际寻路、排队、进门、厂内卸矿再入账，完成后自动继续采矿，不在命令发出时提前获得资金。

累计消灭敌人价值严格大于自身造价3倍后晋级一次；相等时尚不晋级。敌方单位/建筑按造价累计，未完工脚手架按已支付价值计算；友军和普通中立物不提供经验。舰载机的击杀计入仍存活的母舰；星级母舰的威力增益也作用于实际舰载机攻击。运输载具及随其损失的乘员，价值归实际击毁者。

| 星级增益 | 幅度 |
|---|---:|
| 最大生命 | +15% |
| 伤害 | +10% |
| 攻击速度 | +10%（间隔÷1.1） |
| 射程 | +8% |
| 护甲 | +10% |
| 持续恢复 | 每秒最大生命的0.5% |

晋级时补上新增生命容量，维修/拖救/机场服务使用星级上限；原长钉自修复规则仍适用。生命条旁显示金色五角星，星级车辆具有更深的势力涂装与金色服役条纹。[外观对照](../../artifacts/rts_v3_visuals/veteran_vehicle.png)。经验和晋级随存档保存。

## 空军与海军

可购买飞机数量为正典4、重锤4、长钉4、天翼5，另有4个内部舰载机定义，不将它们用于凑玩家可购买机种数量。正典侦察机采用双尾、长直翼和扫描盘，与战斗机区分。

飞艇和新增直升机永久飞行，不降落、不消耗弹药、不占停机位；普通固定翼执行完移动后围绕待命地点盘旋。固定翼弹尽返航、机位与付费维修继续生效。

每军舰艇扩至8类：原运输船/护卫舰/特色舰，加潜艇、两栖装甲、运兵气垫船、远程支援舰和小型航母。

- 潜艇需要声呐发现及反潜武器才能攻击；护卫舰、反潜直升机等提供反潜闭环。
- 两栖装甲以真实2格完整扫掠跨越可通行海岸，陆地按地面目标受击；工厂和船坞均可生产，工厂版本从内部经旋转正门实际驶出。
- 气垫船可实际登载、跨水岸运输及卸载步兵。
- 远程支援舰提供远距离火力。
- 小航母实际派出最多2架舰载机攻击并回收，飞机损失后按时间重建，不用一段普通炮弹冒充航空攻击。

AI按资金与科技生产新增舰种，岛屿工厂可生产两栖部队；气垫船计入运输容量规划。实例、路由和存档沿用同一套实际单位状态。
