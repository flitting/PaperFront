# 本轮试玩反馈修订 · 2026-10-06

当前源码已按反馈修订，通过仓库 `./run.sh` 重新启动。

## 声线与单位身份

此前各语音虽配置同一 Gemini 预设，但逐句生成与不同表演方向仍会出现听感漂移。现已重制288条语音，按阵营与步兵、车辆、空军建立12个固定档案；每个档案的24条语音使用同一 Microsoft MAI 托管说话人、固定节奏及保持音高的处理。运行时跨动作使用同一档案，并拒绝声源标识不符的录音。

69种单位的模型与语音路由一致性检查通过1296项：立体模型跨动作复用同一节点和网格，纸片步兵各动作使用同阵营、同兵种资源与服装配色。

铁钉定心炮 `iron_advanced` 使用铁钉车辆组。其“火控调好了，开始射击”和“炮管稳定，继续射击”两句重新制作并通过单独识别复核。整组自动听觉检查覆盖全部288条，最后未标出男女声切换或不同说话人片段。另确认并修复了少量额外词句、漏词、口吃等问题，保持 WAV、字幕和规则对白一致。自动听觉检查与 ASR 不等同于人工逐句试听或生物声纹证明。

## 三档战斗音乐

保留菜单曲和各地图舒缓配乐，增加《交战推进》交战层 `battle_engaged`（约64秒），形成舒缓、普通交战、密集交战三档。

普通交战进入较克制的中间曲；只有同一区域至少8个近期有效射手、持续火力达到阈值，才会升级到原激烈曲。分散在地图各处的小交战不会合并为高密度战斗。中间层保留短暂铺垫，密度下降则退回中间层。

每次淡出与淡入各约2秒：当前曲缓慢降至零后，下一曲从低音量逐渐上升。停火也沿此流程回到地图配乐，替换之前的立即切断与0.8秒静默策略。装填间隔和步兵换目标继续保持有效交战。菜单、静音和退出各保持其正常优先级。

## 播放器与动画演示

Wiki 音频浏览器进入页面即暂停常规配乐与战场声音，停止、播放结束、换曲后仍保持暂停；离开该页或关闭、禁用后恢复正常配乐位置。目录361项，仅包含当前使用的288条语音、59个音效和14首音乐。

增加播放／暂停、停止、重播、下一段、可拖动音频进度、0.5–2倍速度和独立试听音量。分类音量与全局静音仍有效，不改变保存的音量偏好。

演示区覆盖全部27个音效族及语音情境：开火、弹着、毁坏、展开、施工、移动、投弹、装填、选中、命令、生产、交付、出售、低电、结果和错误提示都有对应模型或场景。示例使用真实单位／建筑模型；循环发动机和履带显示运动。纯音乐与环境背景声留空。

演示使用独立帧时钟，不读取音频拖动位置；拖动至结尾也不会提前终止演示。重播同时重启音频与演示，显式暂停、停止、换条目或关闭控制演示生命周期。演示场景没有声音播放器，不启动真实战局，只播放当前选中的那一段音频。

## 爆炸、碎片与地面痕迹
