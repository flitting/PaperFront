# 手绘桌面模型 3D 升级 · 2026-10-01

用户最新要求覆盖旧任务书中冲突的纸片、建筑朝向和坦克停稳开火限制。目标是尽量接近 [用户概念图](concept_3d_reference.png) 的空间体积、构图密度、冷暖色彩和手制氛围，不复制参考素材，不转向写实军事风格。

## 本轮设计

- 车辆和全部建筑采用真正有体积的原创简化模型。坦克分离车体与炮塔，炮塔世界朝向独立，炮口标记与炮管后坐一致。步兵保留手绘剪纸。
- 攻击移动沿合法路线持续前进，同时在射程内索敌、转炮塔与开火；指定攻击追击目标。普通移动执行行军，不自行开火；步兵交战停下。炮弹固定落点、冷却、友伤、碾压与死亡后继续飞行等规则保留。
- 暖色主方向光、冷色环境填充、动态阴影与适量 SSAO。纸张纤维、暗墨边线、哑光色块为模型提供手工感，避免写实金属与高光。
- 蓝/红屋顶、车体与旗帜，深绿色森林簇，蓝色河流和矿晶，暖色岩壁与地面形成冷暖关系。体积树木、岩石、石木桥梁、栅栏和少量遗迹打破空旷地面。
- 不规则四层高地、悬崖、曲折河岸和合法坡道与实际通行数据一致。双方平坦基地与近矿等价，可毁桥外始终有永久陆路；战斗地带保留可辨识空间。
- 右侧建造栏滚轮只滚动条目。加工进度放在对应建筑/生产单位条目下缘；建筑就绪时条目加深，显示“就绪 · 点击放置”，并保留取消不退款提示。
- 默认透视俯角30°，菜单与R/T支持20–45°，继续保留Q/E环绕和中键平移。完整建筑与景物不会追随镜头旋转；镜头不改变模拟朝向、碰撞或射击规则。
