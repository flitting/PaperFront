# 2026-10-07 电脑 AI 与首轮数值调整

> Historical evidence for the dated build/experiment only; not v0.8.0 acceptance. Generated `artifacts/` evidence is local output and is not bundled with the source repository. Current checks: [release notes](release_notes.md).
> 此文仅保留对应日期的实验或旧工具回执，不代表当前发行版验收。

已接入四阵营共用的电脑 AI，完成无渲染对照实验，并将候选 E 的数值写入 `data/rules.json`。本轮降低了部分基础兵种的性价比差距，恢复了正典步枪与反甲兵的预算克制关系；完整对局仍显示重锤、正典较强，天翼的开局与策略仍需继续观察。

## 最终实验设置

- 固定「明原对称场」，标准总部及每方 4000 初始资金，没有额外单位、建筑、科技或收入。
- 同一冻结 AI `land_skirmish_v3_emergency_defense`、普通难度、balanced 策略、战争迷雾开启。
- 四阵营两两对阵，各交换出生侧：每套规则 12 场跨阵营对局；另外每阵营一场同阵营镜像对照，共 16 场。
- 原始规则与候选 E 各 16 场，共 32 场；每局上限 900 游戏秒，步长 0.05 秒。
- 另用正常游戏的 1/30 秒步长，复验正典—天翼两个出生方向、两套规则，共 4 场。
- 规则、AI、模拟与地图源码均记录校验值；最终报告确认两套规则的 16 个条件可直接配对，运行期间代码没有变化。

镜像地图不会随种子生成新的地理条件。这些是确定性实验条件，不是独立随机样本，也不是玩家总体胜率估计。到达时间上限的对局只记为未结束，未按资产强行判胜。

## 完整对局结果

下表排除同阵营镜像。每个阵营在每套规则下参加六场跨阵营对局。

| 阵营 | 原规则：胜 / 负 / 未完 | 候选 E：胜 / 负 / 未完 |
|---|---:|---:|
| 正典军团 | 5 / 0 / 1 | 4 / 1 / 1 |
| 重锤军团 | 4 / 1 / 1 | 5 / 0 / 1 |
| 长钉军团 | 0 / 4 / 2 | 1 / 5 / 0 |
| 天翼教团 | 0 / 4 / 2 | 1 / 5 / 0 |

全部 32 场有效，无进程超时或脚本错误。基线共 10 场真实终局、6 场未结束；候选共 12 场真实终局、4 场未结束。其中正典在同阵营镜像里各有一场胜负终局，其余三场镜像均未结束；这些结果不计入阵营强弱表。

候选使正典不再包揽它所有已结束的跨阵营对阵，长钉和天翼也各出现一场胜利。需要明确：这两个新增胜场来自长钉与天翼彼此的对阵，它们仍未击败正典或重锤。重锤成为本组条件中的强势方，天翼依然输给正典的两个出生方向。完整对局并未证明阵营整体差距已缩小；本轮可确认的收益是成本纠偏、部分等预算战斗差距降低及基础兵种克制恢复，不能宣称四阵营已达到相同强度。

30 Hz 复核的四场均仍由正典战胜天翼，确认这个弱势方向没有消失。结束时间对步长敏感，不能把 0.05 秒实验的精确秒数当作正常游戏固定时间。

| 天翼基础步枪兵生命 | 63 | 80 |
| 天翼矿车价格 | 798 | 600 |
| 天翼基础坦克价格 | 1265 | 900 |
| 天翼基础坦克生命 | 405 | 480 |
| 天翼矿厂价格 | 1550 | 1350 |
| 天翼工厂价格 | 1350 | 1200 |
| 正典反甲兵对步兵伤害倍率 | 默认 1.0 | 0.55 |

正典保留快速、便宜的装甲与较强步兵，天翼保留较低地面装甲和高科技/航空特点。天翼坦克每千资金的对装甲理论 DPS 约 43.48，与调整后的正典 44.87、长钉 43.70 接近；其生命与装甲仍更脆弱。天翼矿车仍比正典贵，生命与装甲较低；采矿速率和免费初始矿车规则没有改变。

正典反甲兵原本能以单发 112.5 伤害秒杀基础步兵。步枪兵涨价后，1424 资金的八名反甲兵在两个朝向都击败了 1430 资金的十三名步枪兵。改为 0.55 后，步枪兵在两个朝向都获胜，分别存活九、十名。装甲、建筑伤害及穿透、射程、射速保持原值。

作为独立诊断，另做了两套规则各十二场、真实投入差不超过 0.66% 的混编战斗，结清所有在途炮弹。原规则天翼 0/6 胜，候选 D 为 3/6；正典获胜时平均剩余资产从 56.3% 降到 44.6%。这组测试覆盖 D，不能冒充完整候选 E 的循环赛结果；E 的额外反甲步兵倍率由上面的四场定向对照验证。

## AI 与实验中修正的问题

共用规划器处理经济、兵种组成、科技、侦察、防守和进攻。阵营适配器提供各自的生产与建设偏好：重锤的工程施工与钻塔、长钉的付费铁路、天翼的标定/束流与航空、正典的步兵装甲混编。三种策略仍可用于后续实验。

- 建筑保留交通间隔，避免把矿车堵在矿厂出口；部队在基地之外集结。
- 工程兵不再被防守命令反复打断，规划器保留脚手架剩余施工款并接管中断施工。
- 幸存进攻部队继续清理敌基地，忽略不影响胜负且不被常规索敌选中的铁路等目标。
- 所有阵营在可见武装敌军靠近、己方兵力不足时暂停可选扩张，优先付费补防守兵；没有增加视野或给予资源。
- 修正统计中的矿车状态：空命令队列不再等同闲置，自动采矿与等待/堵塞分开记录。

探索阶段跑过多策略及较早版本 AI 的对局。它们用于定位上述问题，部分实验主动停止，保留在 `artifacts/ai_balance_20261007/` 中并标记为探索用途；没有混入最终 32 场同版本数值对照。
