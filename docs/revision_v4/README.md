# 模型、海军与界面修订

本轮按最新反馈调整现有纸板 RTS。模型显示大小与实际寻路占地分别处理；旧存档保留自己的规则快照，新的海军编制请在重启项目后新开对局查看。

## 模型与辨识

- 正典的校正炮、裁定电磁炮，以及长钉矿车改按底盘归一尺寸，长炮管与采矿设备不再把整个车体压小。原“校对炮”改名“裁定电磁炮”，正式名称“终稿裁定电磁炮”。
- 长钉矿厂采用蒸馏塔、冷凝器与外露齿轮；天翼矿厂采用折叶分离器与矿晶核心。两者都保留可实际通过的正门卸矿通道及开门动画。
- 长钉装甲列车为蒸汽机头、重炮车厢、防空车厢三节，近、中、远三档均保留完整车列。参考了[《战地》装甲列车意象](https://news.ea.com/press-releases/press-releases-details/2016/In-Battlefield-1-No-Battle-Is-Ever-the-Same/default.aspx)，保留现有纸板与长钉机械风格。车厢炮位属于本轮模型设计，武器规则仍沿用列车原有武装。
- 裁决重坦补回白色主装甲，保留势力标记及固定辅色。它在现有规则中属于天翼教团。
- 所有船舶的视觉尺寸为此前两倍，实际寻路占地不变。受影响的47张模型生产头像已重新渲染，四艘专职防空舰使用独立头像。
- 天翼基础电站没有工业烟气；有烟囱的电站保留对应烟气。受损烟气沿用原有规则。
- 22种步兵仍为人物纸片，保留0.6显示比例、1×1碰撞、原有朝向及纸片厚度；从头部、服装、背具、武器及站姿区分阵营与兵种。

## 海军编制与舰载机

每家均保留基础护航、运输、防空、重型舰及远程炮火支援五类职责，再配置不同的特色单位。

| 阵营 | 可购舰艇数 | 特色分配 |
|---|---:|---|
| 正典军团 | 6 | 独家轻型航母 |
| 重锤军团 | 6 | 独家两栖装甲车，工厂和船坞均可生产 |
| 长钉军团 | 6 | 独家潜艇 |
| 天翼教团 | 5 | 气垫船承担登陆运输 |

其余旧海军定义保留以兼容已有单位；新规则中从生产、AI与Wiki名册隐藏，也不能绕过生产接口购买。每家新增一艘专职防空舰。

舰载机逐架从母舰甲板滑跑、离舰爬升，再进入正常攻击航线。舰载内部飞机的显示比例适配甲板，2×2逻辑占地保持；普通飞机显示比例不变。位置和高度属于实际模拟状态，随移动中的母舰更新；起飞检查空域间距，起飞中的存档可以继续，经验伤害仍归属母舰。

## 飞行与操作界面

固定翼待命时，盘旋沿实际位置的切向前进，并提前绕开其他飞机。避让保留运动方向，避免追逐越过自己的盘旋目标造成反复掉头。普通移动、返航、降落仍使用各自原有流程。

右侧选中说明直接显示定位（防空、反坦克、反步兵、运输等）、实时护甲和武器穿甲。星级护甲使用实际加成值，航母显示舰载机穿甲。

设置分为“战局、声音、画面、镜头、调试”标签，战局页在未开局时隐藏。新战局配置分为“军团、战场、部署”三页，切换页面保留设置与地图预览；设置期间对局继续暂停。
