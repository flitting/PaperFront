# 长钉铁路规则接入与验证（2026-10-07）

`rail_network.gd`维护按所属玩家划分的正交无环图；铁路作为可摧毁建筑实体保存，但从静态碰撞、自动索敌及终局建筑计数排除。手动、延伸批量与处理厂自动铁路共享同一放置验证器，错误直接返回中文原因。三向岔道默认缺北口，可在待放置订单旋转；相邻岔道、第四端口、普通轨三叉、任何环以及不合法的贴边连接都会拒绝。普通转弯由连接方向自动表达。

实体渲染字段：`rail_mask`实际连接，`rail_ports`可用端口，位序东=1、南=2、西=4、北=8。`rail_rotation` 0/1/2/3依次缺北/东/南/西。普通轨使用mask；岔道使用ports绘制三个端口。UI旋转调用`sim.rotate_rail_order(team, quarter_turns=1, channel="auto")`。铁路沿用defense队列，`defense_extension`提供最多6格直线延伸，完整批量先验证后扣款创建。

普通地面单位在己方铁路上速度严格2倍。选择路线时轨内每格成本0.5，并仅为实际需要的上下轨各加入0.35距离成本；没有真实等待时间。普通路线比较起终点附近各5个接入点；铁路车辆仅使用连通铁路图。铁路段单位之间免碰撞，静态障碍和AOE逐个结算仍生效。原生单位派发与移动避让在存在铁路时使用脚本分支以遵守新增机制；静态几何查询仍使用原生模块。大型铁路军团的性能需另行测量。

处理厂出口为建筑南侧带碰撞余量的格中心。10格内矿脉自动尝试合法正交路线，无矿只生成一个出口轨；有矿但无合法路线时保留出口轨并提示手动连接。自动附赠铁路不额外收费。工厂矿车/列车订单正常生产到完成，出口无己方合法轨道则保留队列并显示等待铁路连接；接轨后自动出厂。轨道毁坏增量刷新图版本，列车/矿车立即重算，桥毁同步摧毁桥面铁路。

验证：`godot --headless --path . --script tests/rail_network_tests.gd`，60项实际断言通过，包括弯轨/岔道/禁环/批量/所有权/禁止占领/精确2倍位移/铁路重叠/断轨、默认原生开启的真实step、矿车真实采矿、工厂真实队列与开门驶出、桥毁轨毁、重叠AOE，AI矿旁选址/付费工厂接矿网，以及旋转订单存读档。该脚本不验证渲染截图；近中远模型及界面截图由综合验收负责。

AI处理厂选址同时验证建筑本体、10格矿源及真实南出口；出口受阻不再永久标为自动铺轨完成，会保留错误原因并间隔5秒重试。长钉工厂生产铁路矿车/列车前会尝试付费接通矿点铁路，失败时改产普通坦克，避免无轨订单堵塞整厂。科技解锁后AI会周期性选择列车。

铁路的自动索敌contact mask置0，但保留完整combat spatial对象供强制攻击与AOE；因此有铁路时仍使用原生nearest目标查询。站在同一轨道格内的短距离移动也明确验证为2倍速度。
