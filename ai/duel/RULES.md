# Alpha / Beta 对抗规则

此规则由用户要求制定。两方只能维护自己的策略、采集器、复盘以及记录副本。

1. **禁止偷看对方代码。** 不得读取、搜索、导入、请求或通过动态加载查看对手当前或历史源码、冻结副本、diff、内部记忆和私有思考。不得向对手 agent 索取策略信息。只读主 agent 指定的本方 review 文件；不读原始完整报告中的对方私有字段。
2. 模块运行时只使用宿主给出的观察与本方记忆；不得访问文件、网络、引擎单例或加载其他脚本。可以读取公开接口文档、公开共同执行层与游戏规则来编写模块。不得修改公共引擎、数值、裁判或其他方文件。
3. 策略路径为 `ai/duel/alpha.gd` / `beta.gd`；数据采集器为 `alpha_recorder.gd` / `beta_recorder.gd`；复盘为 `alpha_reflection.md` / `beta_reflection.md`；本人记录副本目录为 `alpha_records/` / `beta_records/`。各方可以增加、重组自己的记录和分析数据，但不得伪造裁判原始证据或胜负。
4. 固定 Kestrel 同阵营、对称地图、正常初始资金/难度、1/30 秒步长。每轮两个固定种子，每个种子换边两局，共四局；同轮双方策略与采集器全部冻结。
5. 只有确定的整轮败者或数学上已不能赢整轮的原挑战方，允许在主 agent 指示后修改。整轮胜者的 AI 决策源码保持 SHA256 不变；双方采集器均可在轮次之间改进，且不得改变游戏行为。未完成或错误局不伪装成胜负。双方不得自行启动额外正式对战；统一由主 agent 裁判运行。
6. 当前同一对冻结版本最近四场有效已结束换边胜负局，双方胜率都在 40%–60% 时停止（四场即 2:2）。不能混用旧版本凑胜率。
7. 或者，同一败者连续修订四次仍未赢得对同一冻结对手的轮次，则停止并报告追赶失败。只修改采集器不计一次 AI 策略修订，仍需记录确实需要采集的信息。
8. 每方以赢得每一场为目标，禁止按种子或席位故意放弃、让局凑出 50%；可针对左右差异改进正常策略。
9. 主 agent 保存未经改写的原始统计、事件、存档、决策日志、源码快照及哈希，并提交结果报告。

接口详细说明见 `docs/independent_ai_duel.md`。

未完成局不计为败局。若原挑战方已胜场加全部未完成局仍不超过固定原冠军的已胜场，则挑战方不能赢整轮，可继续修订；冠军决策源码保持。详细上界判定见 docs/independent_ai_duel.md。
